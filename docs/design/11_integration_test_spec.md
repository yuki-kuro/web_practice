# 結合テスト仕様書

## テスト対象

画面操作を起点とした、ブラウザ → Servlet → DB → 画面表示までの一連の動作確認

## テストケース表の見方

| 列 | 説明 |
|---|---|
| テストID | IT-画面略称-連番 |
| テスト内容 | 何を確認するか |
| 操作手順 | テスト実施手順 |
| 入力値 | フォームに入力する値 |
| 期待結果 | 画面表示・DB状態 |
| 合否 | テスト実施後に記入（OK / NG） |

## 6. セキュリティ（IT-SEC）

| テストID | テスト内容 | 操作手順 | 入力値 | 期待結果 | 合否 |
|---|---|---|---|---|---|
| IT-SEC-01 | CSRFトークンなしのPOSTで403エラーになる | 開発者ツールで hidden の csrfToken を削除してフォーム送信 | csrfToken = なし | 403 Forbidden が返る | |
| IT-SEC-02 | 不正なCSRFトークンのPOSTで403エラーになる | 開発者ツールで csrfToken の値を書き換えてフォーム送信 | csrfToken = "invalid" | 403 Forbidden が返る | |

| IT-SEC-04 | 商品名にシングルクォートを含む値が正しく保存・表示される | 商品名に `'` を含む値を登録 | 商品名 = "It's" | 正しく登録・表示され、SQLエラーが発生しない | |
