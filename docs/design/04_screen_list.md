## 2. 商品検索

| 項目 | 内容 |
|---|---|
| URL | /SearchProduct |
| メソッド | GET |
| 概要 | 商品名で部分一致検索し、結果を一覧表示する。未入力時は全件表示 |

**入力項目**

| 項目名 | 種別 | パラメータ名 | 制約 |
|---|---|---|---|
| 商品名 | テキスト | keyword | 50字以内。省略可（省略時は全件表示） |

**表示項目**

| 項目名 | 説明 |
|---|---|
| 商品コード | 3桁ゼロ埋め（例：001） |
| 商品名 | - |
| 単価 | カンマ区切り（例：130,000） |
| 編集ボタン | 商品変更・削除画面へ遷移 |
| エラーメッセージ | バリデーションエラーまたは0件メッセージ |

---

## 3. 商品登録

| 項目 | 内容 |
|---|---|
| URL | /RegisterProduct |
| メソッド | GET（フォーム表示）/ POST（登録処理） |
| 概要 | 商品名と単価を入力して新規商品を登録する |

**入力項目**

| 項目名 | 種別 | パラメータ名 | 制約 |
|---|---|---|---|
| 商品名 | テキスト | registerProductName | 必須・50字以内 |
| 単価 | テキスト | registerPrice | 必須・整数・1〜1,000,000 |
| CSRFトークン | hidden | csrfToken | システム自動セット |

**POST 処理結果**

| 結果 | 遷移先 |
|---|---|
| 登録成功 | 商品検索画面へリダイレクト（PRGパターン） |
| バリデーションエラー | 商品登録画面へフォワード（エラーメッセージ表示） |
| CSRF不一致 | 403 Forbidden |

---

## 4. 商品変更・削除

| 項目 | 内容 |
|---|---|
| URL | /EditProduct |
| メソッド | GET（フォーム表示）/ POST（更新・削除処理） |
| 概要 | 選択した商品の商品名・単価を変更、または論理削除する |

**GETパラメータ**

| 項目名 | パラメータ名 | 説明 |
|---|---|---|
| 商品コード | productCode | 商品検索画面の編集ボタンから渡される |

**入力項目**

| 項目名 | 種別 | パラメータ名 | 制約 |
|---|---|---|---|
| 変更後 商品名 | テキスト | productNameToChange | 必須・50字以内 |
| 変更後 単価 | テキスト | priceToChange | 必須・整数・1〜1,000,000 |
| CSRFトークン | hidden | csrfToken | システム自動セット |

**表示項目**

| 項目名 | 説明 |
|---|---|
| 商品コード | 変更不可（表示のみ） |
| 変更前 商品名 | 変更前の値（表示のみ） |
| 変更前 単価 | 変更前の値（表示のみ） |

**POST 処理結果**

| 結果 | 遷移先 |
|---|---|
| 変更・削除成功 | 商品検索画面へリダイレクト（PRGパターン） |
| バリデーションエラー | 商品変更・削除画面へフォワード |
| 競合エラー（楽観的排他制御） | 商品変更・削除画面へフォワード（エラーメッセージ表示） |
| 売上実績ありの単価変更・削除 | 商品変更・削除画面へフォワード（エラーメッセージ表示） |
| CSRF不一致 | 403 Forbidden |

**ビジネスルール**

- 売上実績がある商品は**単価の変更・削除が不可**（商品名の変更は可）
- 他ユーザーが先に更新していた場合は**楽観的排他制御**によりエラー

## 5. 売上登録

| 項目 | 内容 |
|---|---|
| URL | /RegisterSales |
| メソッド | GET（画面表示）/ POST（追加・登録処理） |
| 概要 | 商品と数量を選択して一時リストに追加し、まとめてDBに登録する |

**入力項目（追加フォーム）**

| 項目名 | 種別 | パラメータ名 | 制約 |
|---|---|---|---|
| 商品名 | セレクトボックス | productCodeToAdd | 必須（「選択してください」以外を選択） |
| 数量 | テキスト | quantityToAdd | 必須・整数・1〜1,000 |
| CSRFトークン | hidden | csrfToken | システム自動セット |

**表示項目**

| 項目名 | 説明 |
|---|---|
| 売上日 | 当日の日付（yyyy/MM/dd形式） |
| 追加済み商品リスト | セッションに保持中の一時リスト（商品コード・商品名・数量） |
| 当日売上一覧 | DBに登録済みの当日売上（商品コード・商品名・数量） |

**POST 処理結果**

| ボタン | 処理 | 結果 | 遷移先 |
|---|---|---|---|
| 追加 | 一時リストに追加 | 追加成功 | 売上登録画面へフォワード |
| 追加 | 一時リストに追加 | バリデーションエラー | 売上登録画面へフォワード（エラーメッセージ表示） |
| 登録 | DB一括登録 | 登録成功 | 売上登録画面（一時リストクリア後） |
| （両方） | - | CSRF不一致 | 403 Forbidden |

## 6. CSVダウンロード

| 項目 | 内容 |
|---|---|
| URL | /CSVDownload |
| メソッド | GET |
| 概要 | 商品別売上集計をCSVファイルとしてダウンロードする |

**入力項目**

| 項目名 | 種別 | パラメータ名 | 制約 |
|---|---|---|---|
| ダウンロード種別 | ボタン | download | 「商品別売上集計CSV」または「指定年月商品別売上集計CSV」 |
| 指定年月 | テキスト | month | 指定年月CSV選択時は必須。yyyy-MM形式。2020-01以降かつ現在月以前 |

**CSVフォーマット**

| カラム | 内容 |
|---|---|
| 商品コード | - |
| 商品名 | - |
| 単価 | - |
| 数量 | 集計期間の合計数量 |
| 金額 | 単価 × 数量 の合計 |

**処理結果**

| 結果 | 遷移先 |
|---|---|
| ダウンロード成功 | CSVファイルをダウンロード |
| 対象データ0件 | CSVダウンロード画面へフォワード（エラーメッセージ表示） |
| バリデーションエラー | CSVダウンロード画面へフォワード（エラーメッセージ表示） |
